本站的文章使用 Markdown 保存。以后添加学习笔记时，只需要填写标题、日期、分类、标签和正文，保存后 GitHub 会自动发布网站。

## 建议的笔记结构

1. 今天学习了什么
2. 最重要的三个知识点
3. 尚未解决的问题
4. 下一步准备做什么

学习笔记的第一个分类使用 `学习`，它就会自动出现在网站的“学习”页面中；普通日记的第一个分类使用 `日记`。

详细操作方式可以查看仓库根目录的 `WRITING_GUIDE.md`。
