今天用一篇简短的学习记录测试个人网站的更新流程。

## 今天学到了什么

GitHub Pages 可以把仓库中的静态网站公开发布。文章提交到 `main` 分支后，GitHub Actions 会自动执行构建，并把生成的页面部署到个人网站。

## 关键步骤

1. 在 `_posts` 目录新增一篇 Markdown 文章。
2. 在文章开头填写标题、日期、分类和标签。
3. 提交并推送到 GitHub。
4. 等待自动构建完成，再刷新网站。

## 今日小结

内容与网站代码分开保存后，日常更新只需要专注写 Markdown，不必每次修改页面结构。这篇文章也是一次从写作到自动发布的完整验证。
